## Short Interview Introduction

> I built TruthFit to test whether a resume actually proves the requirements in a job description. The interesting work was not only the model call. I separated Next.js, FastAPI, PostgreSQL, and RQ; added account ownership and data retention; made provider failures durable; constrained output with Pydantic; and built security, database, browser, load, and LLM-evaluation tests. The remaining milestone is deploying the product stack and validating model quality with a larger human-reviewed dataset.
