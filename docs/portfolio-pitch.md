## Short Interview Introduction

> TruthFit checks whether a resume supports the requirements in a job description. I built the interface with Next.js, the API with FastAPI, and background processing with RQ. Reviews are stored in PostgreSQL and scoped to the signed-in account. The project includes deletion and retention controls, validated model responses, and tests for access control, database operations, browser flows, and model output.
